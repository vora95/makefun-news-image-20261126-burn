## How it works

`main.py` (standard library only) copies the pre-rendered `entry.png`
(1024×1024) into `$MAKEFUN_OUTPUT_DIR/entry.png` and verifies it twice
— the bundled source before writing, and the written file afterwards:
identical bytes, SHA-256, dimensions and size must all match.

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
```
